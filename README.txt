TBS MOBILE PWA v2.0 - GIAI DOAN 1 (DOC LAP)

1. Giai nen ZIP. Tao GitHub repository PUBLIC ten tbs-mobile-pwa.
2. Tai len index.html, app.js, manifest.webmanifest va thu muc icons/ dung cau truc.
3. GitHub Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Mo https://TEN-TAI-KHOAN.github.io/tbs-mobile-pwa/ tren Safari iPhone.
5. Chia se > Them vao Man hinh chinh > Open as Web App > Them.
6. Them cac URL /exec trong giao dien. Khi bam vao app con, Safari co the mo trang rieng va banner Apps Script.

AN TOAN: Ban nay KHONG sua Code.gs, Index.html, Google Sheets, va KHONG tu dong dong bo danh sach APPS.
Danh sach luu trong localStorage cua trinh duyet/PWA, co the mat neu xoa du lieu website. Dung Xuat JSON de sao luu.
KHONG luu du lieu nhay cam, token, mat khau trong JSON.
De dong bo Google Sheets, can thiet ke backend xac thuc rieng; khong cong khai Apps Script execute-as-owner.
